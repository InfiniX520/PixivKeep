## 重放

在新的隔离 checkout 内使用原共用解释器，设置 PYTHONNOUSERSITE=1、PYTEST_DISABLE_PLUGIN_AUTOLOAD=1。独立测试从本文件相邻 evidence 自动定位仓库；也可用 PIXIVKEEP_AUDIT_REPO 显式指定固定 checkout。

```powershell
# $auditOutput 必须是新建、未使用的本批绝对路径，不能复用旧 basetemp。
& $py -s -B -X utf8 -m pytest docs/audits/2026-11-15-u1u2-independent/evidence/test_independent.py -q -s -p no:cacheprovider --basetemp="$auditOutput/probe_tmp" --junitxml="$auditOutput/probes.xml"
```

完整执行脚本/日志/JUnit/源码哈希与脏树摘要留在本批 .runtime；公开摘要见 results.json。无需安装、登录或取回图库。网页查证仅使用 W3C PNG 官方规范，没有运行外来程序。
